Проєкт виконано повністю самостійно[cite: 1]:
* Налаштовано серверну логіку та маршрутизацію (роутинг) у файлі `app.py` на Python (Flask).
* Розроблено структуру шаблонів у каталозі `templates/` (`index.html`, `news.html`, `tournaments.html`, `about.html`).
* Підключено та налаштовано адаптивну верстку за допомогою Tailwind CSS.
* Ініціалізовано Git-репозиторій та виконано деплой коду на GitHub: [Основний коміт з реалізацією проєкту](https://github.com/and701/lab3/commit/84714f1)[cite: 1].

### Труднощі, що виникли, і як їх вирішено
1. **Відображення стилів:** Спочатку виникли проблеми з коректним рендерингом стилів у браузері. Проблему вирішено шляхом правильного підключення актуального скрипту Tailwind CSS через CDN у секції `<head>` HTML-шаблонів[cite: 1].
2. **Налаштування Git та відправка на GitHub:** Під час першого пушу виник конфлікт назв гілок (`master` локально та `main` на GitHub), а також затримка через активний процес локального сервера в терміналі. Проблему вирішено зупинкою сервера, перейменуванням локальної гілки командою `git branch -M main` та прив'язкою віддаленого репозиторію[cite: 1].

Під час виконання лабораторної роботи було опановано базові принципи створення вебдодатків на мікрофреймворку Flask та організації маршрутизації запитів[cite: 1]. Набуто практичних навичок роботи з шаблонізатором Jinja2, швидкої адаптивної верстки за допомогою Tailwind CSS, а також керування версіями проєкту через Git і GitHub[cite: 1].
